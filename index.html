Прымяненне ўласцівасцей квадратных каранёў

§ 4 · ламповы канспект: тэорыя → практыка → тэст

1. Вынясенне множніка за знак кораня

Выкарыстоўваем уласцівасць кораня са здабытку: a·b = a · b (пры a ≥ 0, b ≥ 0).

49·2 = 49·2 = 72 — множнік 7 вынеслі за знак кораня.
45 = 9·5 = 35;  125 = 25·5 = 55;  5a² = 5·|a|
Алгарытм:
① падкарэнны выраз запісаць здабыткам, які змяшчае квадрат;
② выкарыстаць уласцівасць кораня са здабытку;
③ знайсці корань з квадрата;
④ запісаць здабытак множніка і кораня.
Прыклад. 72 = 36·2 = 36·2 = 62

⚠️ Са зменнымі — толькі праз модуль: 2a²b⁴ = 2·|a|·b², а пры a < 0 атрымаем −ab²2.

2. Унясенне множніка пад знак кораня

① неадмоўны множнік запісаць як корань з яго квадрата;
② ужыць уласцівасць кораня са здабытку «справа налева»;
③ запісаць корань са здабытку.
57 = 5²·7 = 25·7 = 175
23 = 4·3 = 12;  −72 = −98;  −0,53 = −0,75

Са знакам зменнай:
калі a ≥ 0: a7 = 7a²;
калі a ≤ 0: a7 = −7a² (мінус «застаецца жыць» звонку!).

3. Пераўтварэнне ірацыянальных выразаў

Выразы, якія змяшчаюць карані, называюцца ірацыянальнымі.

Прыклад 1

(−7)(−14) ∕ 18·25 = 7·2·7 ∕ 2·9·25 = (72) ∕ (3·5·2) = 7/15

Прыклад 2

18 − 50 + 20,5 = 32 − 52 + 2 = 2(3−5+1) = −2

Прыклад 3 (формулы скарочанага множання)

(7−5)² + (7+5)² − (7−5)(7+5) = 7+5+7+5−7+5 = 22

Прыклад 4 (раскладанне на множнікі)

а) 211 + 11 = 11(2 + 11)
б) 14 − 21 = 7(2 − 3)

Прыклад 5 (скарачэнне дробу)

(56 − 6) ∕ 6 = 6(5 − 6) ∕ 6 = 5 − 6

Прыклад 6 (складаны радыкал)

7+43 = (3+2)² ⇒ 7+43 = 3+2
7−43 = (3−2)² ⇒ 7−43 = |3−2| = 2−3
Сума: (3+2)+(2−3) = 4

4. Пазбаўленне ад ірацыянальнасці ў назоўніку

Калі ў назоўніку просты корань — множым лічнік і назоўнік на гэты корань:

1∕2 = 2∕2;   3∕6 = 36∕6 = 6∕2

Калі ў назоўніку сума (рознасць) — множым на спалучаны выраз (формула рознасці квадратаў):

3∕(5−2) = 3(5+2)∕(5−2) = 5+2
3∕(7+1) = 3(7−1)∕6 = (7−1)∕2

💡 Карысна памятаць: (a)² = a (пры a ≥ 0), a² = |a|, aa = a³ толькі пры a ≥ 0.
